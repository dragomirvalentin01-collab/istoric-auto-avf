# Ulei + Filtre — Audi A4 B6 Avant 1.9 TDI AVF

Live: https://dragomirvalentin01-collab.github.io/istoric-auto-avf/

Simplu, de la zero: doar schimburi de ulei + filtre și notițe libere pentru rest (piese, reparații).

## Ce știe
- Bord: km curent + status ulei (10.000 km / 12 luni, alertă la 1.000 km rămași / depășire)
- + Ulei: data, km, producător (dropdown), specificație (5W-40 505.01), filtre bifate (ulei/aer/combustibil/polen), costuri, service
- Istoric: toate schimburile + ștergere
- Notițe: titlu + detalii + data + km opțional + căutare (aici treci piese, reparații, injectoare, arcuri…)
- Login Google → sincronizare în cloud (proiectul pontaj4, tabele vehicles/oil_changes/notes)
